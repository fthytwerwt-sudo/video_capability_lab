# 参考视频解析执行边界

## 当前定位

参考视频解析只转机制，不迁移资产，不直接复刻，不把参考视频当项目事实。

## 必须输出 reference_to_execution_contract

```json
{
  "reference_effect": "",
  "transferable_mechanisms": [],
  "non_transferable_assets": [],
  "component_mapping": [],
  "acceptance_standards": [],
  "current_status": "待验证"
}
```

## 禁止项

- 不迁移素材路径。
- 不复刻平台 UI。
- 不复刻第三方品牌资产。
- 不把参考视频风格写成项目能力已成立。

## 阻断条件

- 参考视频不可访问。
- 权利边界不清。
- 用户要求一比一复刻。
- 缺少可执行组件映射。
