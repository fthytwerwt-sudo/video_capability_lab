# 组件库

## handwriting_beat_layer（手写字节奏层）

- 组件用途：把短句或关键词按 beat / onset 节奏写入画面。
- 输入：文本、时间点、字体风格、颜色、位置、beat_map。
- 输出：可叠加的文字层或组件配置。
- 适用场景：短句强调、vlog 标注、教学提示。
- 不适用场景：长段正文、需要精确字幕校对的旁白。
- 当前状态：待验证

## split_screen_collage（分屏拼贴）

- 组件用途：将多个画面按网格或不规则版式组合。
- 输入：素材片段、布局、时间轴、边框/间距。
- 输出：分屏 composition 或配置。
- 适用场景：对比、过程展示、节奏剪辑。
- 不适用场景：需要主体细节大画幅查看的片段。
- 当前状态：待验证

## glass_music_card（玻璃音乐卡）

- 组件用途：展示音乐标题、节拍、波形或封面占位。
- 输入：曲目信息、beat_map、颜色、卡片位置。
- 输出：玻璃拟态音乐卡。
- 适用场景：BGM 展示、片头节奏提示。
- 不适用场景：真实音乐平台 UI 复刻。
- 当前状态：待验证

## glass_search_question_card（玻璃搜索问题卡）

- 组件用途：用原创 glass-like 卡片展示问题或搜索意图。
- 输入：问题文本、关键词、入场时间、停留时长。
- 输出：搜索问题卡片层。
- 适用场景：知识型、教学型、vlog 转折。
- 不适用场景：复刻真实搜索平台 UI。
- 当前状态：待验证

## glass_cta_end_card（玻璃 CTA 尾卡）

- 组件用途：在技术样片结尾展示 CTA 或复审提示。
- 输入：CTA 文案、按钮标签、背景状态、结束时间。
- 输出：尾卡组件配置。
- 适用场景：样片回审、动作收束。
- 不适用场景：正式商业转化承诺。
- 当前状态：待验证

## edge_glitch_transition（边缘 glitch 转场）

- 组件用途：在镜头切换时加入边缘扰动。
- 输入：前后片段、持续帧数、扰动强度、方向。
- 输出：转场参数或组件。
- 适用场景：odd 风格、快速切换、强调转折。
- 不适用场景：需要稳定阅读或严肃教学段落。
- 当前状态：待验证
