# 视觉风格预设

## odd_glass（怪趣玻璃感）

- 风格目标：怪趣、轻微错位、透明层次、手作感。
- 颜色规则：高对比点缀色配中性背景，避免整页单一色系。
- 动效规则：微弹跳、边缘扰动、非线性入场。
- BGM 匹配规则：可尝试轻快、切分明显、适合短促卡点的音乐。
- 禁止项：不得复刻第三方 UI，不得把随机 glitch 做成不可读。
- 当前状态：待验证

## apple_like_glass（苹果感玻璃拟态）

- 风格目标：克制、清透、层次细、原创 apple-like glass。
- 颜色规则：浅色或深色背景均可，但玻璃层必须有可读对比。
- 动效规则：缓入缓出、视差、轻微缩放，不做真实 Apple UI 复刻。
- BGM 匹配规则：干净、节拍稳定、不过度抢人声。
- 禁止项：禁止复刻 Apple 官方 UI、图标、品牌资产。
- 当前状态：待验证

## vlog_packaging（vlog 包装）

- 风格目标：生活化、轻包装、镜头节奏清楚。
- 颜色规则：贴近素材色调，少量标题和贴纸辅助。
- 动效规则：轻量转场、字幕节奏跟随语义。
- BGM 匹配规则：不盖过旁白，支持 ducking。
- 禁止项：不得用包装遮挡主体信息。
- 当前状态：待验证

## ecommerce_product_showcase（电商商品展示）

- 风格目标：商品信息清楚、卖点可读、节奏明确。
- 颜色规则：商品优先，辅助色服务阅读和重点。
- 动效规则：卖点逐层出现，避免过度装饰。
- BGM 匹配规则：节奏服务 CTA，不压人声。
- 禁止项：不得把商品视频组件写成真实商业效果已验证。
- 当前状态：待验证
