## 4. 横向审美规则

### 4.1 合格审美标准

1. 已确认：参考视频共同逻辑是 `真实镜头先行`。开场通常是手部、脚步、物件、街景、交通、建筑、水面、花束或灯光，不是说明页。
2. 已确认：剪辑以 `1.5-3 秒微段落` 推进，常见结构是物件特写 -> 城市/空间 -> 情绪字 -> 静物/夜景 -> 平台尾卡。
3. 已确认：文字层是情绪/节奏层，不是解释层。常见形式是 1-3 个词、手写字、serif 大字、拟声字或歌词式短语。
4. 已确认：贴纸和 emoji 是语气标点，不是主体。它们通常只强化一个动作或一个小主体。
5. 已确认：合格画面有 `motif`。例如 hidden moment、海边夜行、麻将街巷、演出、城市 editorial、玻璃/花束、购物街头。
6. 已确认：画面密度来自真实素材的切换，不来自 UI 卡、PPT 边框或组件名。
7. 已确认：黑底或边框可以成立，但前提是它像 scrapbook / film roll 的呼吸空间，不像网页卡片容器。
8. 已确认：结尾都在做 CTA 收束，但只能迁移“结尾收束”机制，不能迁移抖音搜索页或账号页资产。

### 4.2 不合格审美标准

1. `fail_project_language`: 出现 `Remotion`、`capability proof`、`BGM marker`、`component`、`机制设计`、`review` 等内部项目词，判定不合格。
2. `fail_card_ppt_feel`: 大标题、大说明、大边框、静态卡片压过真实镜头，判定不合格。
3. `fail_component_showcase`: 片子像在展示“我有哪些组件”，不是连续视频，判定不合格。
4. `fail_no_motif`: 没有主题母题，只把镜头随机拼在一起，判定不合格。
5. `fail_overlay_overload`: 字、贴纸、边框、分屏同时抢主体，判定不合格。
6. `fail_long_static_layout`: 分屏或黑底停留太久，像 layout demo，判定不合格。
7. `fail_platform_or_brand_copy`: 复刻抖音 UI、搜索框、账号页、二维码、watermark、Apple logo、店铺招牌、品牌包装、车牌、地标，判定不合格。
8. `fail_music_claim`: 只确认有音轨，却宣称精准卡点或音乐理解成立，判定不合格。
9. `fail_v1_repeat`: 再次做成项目说明 / 组件验收 / 技术链路展示，判定不合格。

## 6. v2 demo 可执行规则

本轮不是生成 v2 demo。以下规则用于下一轮 `demo_v2_aesthetic_retarget` 或 `demo_v2_reference_retarget`。

### 6.1 输入字段

| field | required | source | rule |
|---|---|---|---|
| `motif` | yes | 用户或 Codex 从素材中提炼 | 只能是观众可感知主题，如 city_walk、glass_light、object_diary |
| `clip_list[]` | yes | 当前仓库原创/允许素材 | 每段标 `type`、`duration`、`risk`、`usable_range` |
| `word_bank[]` | yes | 原创短词 | 1-3 词，不使用参考原文案 |
| `overlay_style` | yes | 本报告规则 | handwriting / serif / tiny_caption 三选一或少量组合 |
| `cta_copy` | yes | 原创 | 不出现平台搜索框、二维码、账号页 |
| `forbidden_assets[]` | yes | 本报告不可迁移资产 | 作为 validator grep 和人工检查清单 |

### 6.2 10-15 秒时间结构

| time_range | required_shape | acceptance |
|---|---|---|
| 00:00-00:02 | 原创物件 / 手部 / 脚步 / 纹理开场 | 不出现项目标题，不解释能力 |
| 00:02-00:05 | 两到三个真实微镜头快切 | 每个镜头有明确主体，不像素材列表 |
| 00:05-00:07 | 第一个短情绪词或手写字 | 不遮挡主体，不超过 3 个词 |
| 00:07-00:09 | scrapbook / split /遮挡转场之一 | 只做节奏变化，不做布局展示 |
| 00:09-00:12 | motif 回环镜头 + 标题叠层 | 标题表达情绪，不写组件名 |
| 00:12-00:15 | 原创 CTA / review end card | 做视频收束，不复刻抖音 UI |

### 6.3 可迁移机制

- `object_pov_opening`: 物件/手部/脚步开场。
- `micro_montage_chain`: 1.5-3 秒微段落推进。
- `emotion_word_overlay`: 情绪词、拟声字或短英文/中文词。
- `scrapbook_black_canvas`: 黑底作为素材呼吸和分组，不作为说明卡。
- `motif_reprise`: 同类元素在前后两段回环。
- `short_split_or_screen_within_screen`: 短分屏或画中画，只作为节奏点。
- `own_cta_end_card`: 自有尾卡收束。

### 6.4 不可迁移资产

- 平台 UI、logo、watermark、账号 ID、搜索框、二维码、账号页。
- Apple logo、店铺招牌、品牌包装、商标、商业海报。
- 原字体、原贴纸、原 emoji 样式、原文案、原音乐、歌词。
- 可识别人脸、路人、儿童、车牌、交通/站内标识、城市地标。
- 玩偶/IP 形象、演出/艺人画面、手机系统播放控件。
