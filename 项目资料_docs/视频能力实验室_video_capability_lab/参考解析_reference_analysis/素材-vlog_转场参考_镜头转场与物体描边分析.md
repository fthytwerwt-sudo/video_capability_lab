## 3. 一句话总判断

这个参考视频最值得学的不是单个炫技转场，而是“高密度硬切 + 物体/文字/描边接管画面”的组合节奏：每 0.5-1.5 秒换一次视觉主体，用白描边 cutout、前景遮挡和匹配运动让切点不突兀。物体描边主要承担主体分离、贴纸感和转场桥三种功能，尤其适合先做 `object_wipe + thick_white_cutout_outline` 的最小 probe。下一轮更适合先做“一个转场机制 + 一个描边机制”的组合 probe，而不是单独验证复杂全片剪辑。

## 4. 镜头转场方式总览

- 转场整体特点：节奏极快，主要靠硬切和短促视觉接管，不依赖长 dissolve；每次切换都给一个可识别视觉锚点，例如杯子、路缘、建筑边、人物/狗、路灯、缆车、Hello Kitty、车窗、玩偶、吊牌。
- 转场类型分布：`cut（硬切）` 最多；其次是 `object_wipe（物体遮挡擦除）`、`foreground_occlusion（前景遮挡）`、`match_cut（匹配剪辑）`、`mask_reveal（遮罩揭示）`、`flash_cut（闪切）`、`transition_edge_punctuation（转场边缘视觉标点）`。
- 主要视觉触发物：手持杯、手机/脚步、白色路缘线、建筑外轮廓、cutout 人物/狗、杯子贴纸字、路灯/墙边白线、缆车、Hello Kitty、布帘、车窗、玩偶、大字、吊牌。
- 主要运动方向：前进推进、右向/左向横移、向上仰拍、前景自右向左遮挡、从暗到亮的亮度跳变。
- 节奏特点：前 10 秒最密集，平均 0.5-1.0 秒一个视觉事件；10-14 秒稍放慢，用布帘、城市屏幕和街道镜头喘口气；15 秒后用大字和吊牌快速收束到平台页。
- 最值得迁移的 2-4 个转场机制：
  - `object_wipe + glitch silhouette`：1.6-2.0s 杯子轮廓被彩色噪声填充后切到地面阴影。
  - `edge_match_cut`：2.5-3.5s 路缘白线和 7.7-8.5s 路灯/墙边白线用同方向线条接住硬切。
  - `foreground_occlusion`：10.2-11.0s Hello Kitty 被布帘/前景竖向遮挡带到布面镜头。
  - `dark_to_bright_object_cutout`：15.0-16.25s 暗车内玩偶 + 大字跳到亮蓝天空吊牌，靠强反差和白描边接管注意力。
- 不建议迁移的转场机制及原因：
  - 平台主页 / 搜索页式结尾：包含平台 UI，不迁移。
  - 可识别 IP / 商业角色原样使用：Hello Kitty 等只能抽象“cutout 主体 + 厚白描边”的功能，不复制角色。
  - 大量原文案 / 原字体 / 原贴纸连用：可学密度和层级，不复刻字形、字词和排版表面。

## 6. 物体描边方式总览

- 描边整体特点：高对比白描边最常见，常配黑色内线或深色主体；部分片段使用彩色 glitch / chromatic edge，让主体像贴纸或抠图层。
- 描边服务的视觉目的：分离前景、强调主体、制造贴纸感、让硬切更可接受、在转场切点提供视觉锚点。
- 更像贴纸层 / 高亮层 / 抠图描边 / 运动强调层：以 `抠图描边 + 贴纸层` 为主，少数是 `运动强调层` 和 `转场边缘标点`。
- 描边是否和转场绑定：部分绑定。1.6-2.0s 杯子描边直接进入转场；7.7-8.5s 路灯/边线描边用于方向桥；15.5-16.25s 大字/吊牌白边用于结尾转场。
- 描边对本项目的迁移价值：高。它比复杂 3D / 粒子更容易先做 component_probe，但真实可用性依赖抠图、tracking、遮挡和 copy risk 处理。

| `outline_transition_relation` | 描边与转场关系 | 部分是主体分离，部分直接承担转场桥 | 优先做“描边对象接管切点” | `待验证` |
| `implementation_guess` | 实现方式推测 | Remotion 中可用 mask/path/SVG stroke/clip-path；复杂主体可能需 OpenCV mask 或手工 roto | 只是实现方式推测，不代表已实现 | `推测` |
| `probe_priority` | 验证优先级 | P1：`object_wipe + thick_white_cutout_outline`；P2：`edge_match_cut + short stroke`; P3：`foreground_occlusion` | 先验证 P1 组合，成本和收益最平衡 | `待验证` |
| `acceptance_check` | 验收检查点 | 1 秒内能看清前后画面关系；描边不漂浮；切点不靠文字遮丑；不复制 UI/IP | 需要输出 before/after/contact sheet 人审 | `待验证` |
| `failure_check` | 失败判定 | 描边像工程 SVG、mask 边抖、贴纸挡主体、转场只是在遮硬切、平台/IP/copy risk 出现 | 任何一项出现则回到规则/素材选择层 | `待验证` |

## 9. 可迁移机制

### 9.1 立刻值得 probe 的机制

- 机制 1：`object_wipe + thick_white_cutout_outline`
  - 参考来源：`1.60-2.00s` 杯子彩色轮廓、`15.90-16.40s` 吊牌厚白描边。
  - probe 目标：用一个原创前景物体的白描边/遮罩接管切点。
  - reference_rule_link：`55:G.stroke_outline`、`55:D.sticker_type_11`、`56:F.sticker_branch_11_transition_edge`。
- 机制 2：`edge_match_cut + edge_attached_short_stroke`
  - 参考来源：`2.50-3.10s` 道路线、`7.70-8.50s` 路灯/墙边白线。
  - probe 目标：让真实画面边缘线承接前后镜头方向。
  - reference_rule_link：`55:D.sticker_type_05`、`55:E.attach_01`、`55:J.transition_function_judgement`。
- 机制 3：`foreground_occlusion_wipe`
  - 参考来源：`10.20-11.10s` Hello Kitty 到布帘，`13.60-14.80s` 街道到车窗。
  - probe 目标：用真实前景遮挡带出下一镜头，不靠纯 opacity。
  - reference_rule_link：`56:C.route_order`、`56:M.failure_routing_map.sticker_floaty`。

### 9.2 需要更多素材或能力验证的机制

- 机制 1：`chromatic_glitch_silhouette`
  - 需要素材主体边界清晰，并验证彩色噪声不会让画面太花。
- 机制 2：`typography_match_cut`
  - 需要原创短词和层级设计，且要避免原文案/原字体复刻。

### 9.3 不建议迁移的机制

- 机制 1：平台主页 / 搜索页式 end card。
- 原因：包含平台 UI、账号页和可识别界面元素；只能迁移“结尾收束到原创信息页”的功能，不复刻表面。
- 机制 2：Hello Kitty 等 IP 主体原样 cutout。
- 原因：IP / 品牌资产风险高；只能迁移“厚白描边主体 pop-in”的机制。
- 机制 3：原视频大字、原文案、原字体直接复刻。
- 原因：copy risk 高，且本项目需要原创语气和素材锚点。

## 10. 下一轮建议

- 主建议：先验证 `object_wipe（物体遮挡擦除）` + `thick_white_cutout_outline（厚白抠图描边）` 的组合。
- 为什么先验证它：它同时覆盖本参考视频最明显的两个价值点：转场靠物体轮廓发生，描边靠高对比白边把主体从复杂背景里分离；比全片 montage 容易收敛，也比单独做文字层更能证明“参考机制是否能迁移”。
- 最小 probe 应该做到哪一步：
  - 只做 `1.5-2.5s` 局部片段。
  - 使用原创或授权前景物体，不使用参考视频素材。
  - 前 0.5s 显示 A 镜头，0.3-0.5s 物体白描边 / silhouette 接管，后 0.7-1.0s 落到 B 镜头。
  - 输出 contact sheet 或 3-5 张关键帧即可，不需要正片。
- 做到哪算本轮 probe 成功：
  - 最小 probe 验收标准：转场触发物、描边贴合、前后画面关系和 copy boundary 均能被逐帧看清。
  - `acceptance_check`：观众能看出是物体轮廓触发转场，而不是普通硬切。
  - 描边贴住物体边缘，边缘不明显抖动，不挡主体关键细节。
  - 前后画面方向或主体关系能被说清。
  - 报告明确 `待验证`，不写能力已成立。
- 什么情况说明不值得继续：
  - 物体 mask 边缘太抖，白边像漂浮 SVG。
  - 转场只能靠大字遮挡，不能由物体/边缘完成。
  - 需要复刻 IP、平台 UI、原文案或第三方贴纸才像参考。
  - 接入后比原始硬切更乱、更花，影响主体识别。
- 如果先不做实现，下一轮还缺什么信息：
  - 选哪组原创 A/B 素材做前后镜头。
  - 前景物体是否允许手工抠图或只允许自动 OpenCV 粗 mask。
  - 描边风格偏干净白边、手绘粗糙边，还是彩色 glitch silhouette。
  - probe 输出是只要静帧审片，还是允许 1.5-2.5s 本地技术视频。

## 11. 禁止复刻项

- 不复刻第三方可识别素材。
- 不复刻平台 UI。
- 不复刻品牌资产。
- 不复制原视频资产。
- 不复制 Hello Kitty 等 IP 角色表面。
- 不复制原视频字幕、原文案、原字体、账号页、搜索框或水印样式。
- 只迁移镜头机制、描边机制、节奏机制。
