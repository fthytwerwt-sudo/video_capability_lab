# 项目总说明

## 项目身份

已确认：本仓库是 `video_capability_lab`。  
已确认：当前中文暂定名是 `视频能力实验室｜Codex 视频导演能力库`。  
已确认：本项目是视频能力实验室，不是直播项目、不是电商项目、不是视频工厂正式运营项目。

## 项目目标

本项目用于验证、沉淀和复用 Codex 视频执行能力，包括组件、节奏、动效、BGM、参考解析和技术样片能力。

第一阶段目标：建立视频能力实验室基础骨架，并验证 3 个组件级能力。

组件级能力暂定为：

1. Remotion 手写字节奏层：待验证
2. HyperFrames apple glass 卡片：待验证
3. BGM beat_map + 卡点导出：待验证

## 项目不是什么

- 不是正式出片项目。
- 不是直播项目。
- 不是旧电商项目。
- 不是视频工厂正式运营项目。
- 不是外部 API 测试仓。
- 不是素材归档仓。

## 当前能力状态

所有视频能力、组件、样片、BGM、参考解析均为 `待验证`。任何文档提到能力名称，只代表待设计或待 probe，不代表已稳定成立。

## 和旧项目的关系

部分协作机制来自源项目机制包的抽象迁移。已确认：只迁移协作方式、判断顺序、同步规则和执行边界，不迁移旧项目业务结论、素材路径、模型选择或验收结果。

GPT Project 上传包只承载配合机制，不承载项目事实。本项目事实必须读取 GitHub 仓库 `main` 当前文件。

Codex 是执行落库层，负责读取仓库、补执行文件、运行验证、commit、push 和验证远端 HEAD。Codex 不能把本地完成写成远端完成。
