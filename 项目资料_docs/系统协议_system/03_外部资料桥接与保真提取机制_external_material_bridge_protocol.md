# 外部资料桥接与保真提取机制

## 文件定位

本文件规定外部资料、参考视频、截图、用户转述、GPT Project 新上传资料进入本项目时的保真提取和执行桥接规则。

## 触发条件

- 用户提供参考视频、网页、截图、音频、BGM、竞品样片或风格描述。
- GPT Project 上传了新资料，但本仓库还没有对应事实文件。
- Codex 需要把外部资料转成 component probe、验收标准或执行合同。

## 默认动作

1. 先区分 `原始材料`、`保真事实`、`执行桥接`、`推测判断`。
2. 参考视频只提供质量机制，不直接提供本项目事实。
3. 可迁移内容必须拆成组件、输入字段、输出字段、验收标准。
4. 不可迁移内容必须明确列出，包括平台 UI、品牌资产、可识别第三方素材。
5. Codex 默认不知道未写入仓库的 GPT Project 新资料，除非本轮显式读取或转述。

## 例外 / 停止线

- 外部资料真实性无法确认时，只能标 `待验证` 或 `推测`。
- 触及版权、平台 UI、第三方品牌资产或可识别素材时，不得复刻，只能抽象机制。
- 资料不足以产出执行合同，应输出待补字段，而不是编造。

## 失败判定

- 把参考视频、截图或聊天转述直接写成项目事实。
- 只做长摘要，不输出可执行字段和组件映射。
- 复刻第三方 UI / 品牌资产 / 可识别素材。

## 一句话执行口径

外部资料先保真，再桥接成可执行组件；参考可以学机制，不能偷变成项目事实或资产复刻。
